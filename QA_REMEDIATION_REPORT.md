# Galactic Omnivore QA remediation report

Date: 2026-07-29

## Architecture confirmed

- Next.js 15.3.8 App Router with React 18 and JavaScript.
- npm and `package-lock.json`.
- Firebase Authentication, Firebase Admin, and Firestore.
- Polar checkout, subscriptions, customer portal, and signed webhooks.
- Resend-backed transactional email and an operationally gated newsletter.
- Vercel production deployment.
- Node's built-in test runner, Firebase Rules Unit Testing, and Playwright.
