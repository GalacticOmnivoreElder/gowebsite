# GO stamp animation brief

Deliver one transparent PNG sprite strip per stamp: **2048 x 256 pixels**, eight **256 x 256** frames in a single horizontal row. The website already provides keyboard activation, a reduced-motion fallback and a gentle CSS effect, so artwork is optional for launch.

Use frame 1 as the finished still image. Keep the symbol inside a centered 224 x 224 safe area in every frame. Keep the canvas and symbol position fixed. Export straight alpha, with no opaque background, text, watermarks or contact details. GO magenta is #CA2280; use high-contrast light accents that read against the dark site.

Suggested sequence for a short activation: still stamp, slight press, first spark, soft outward burst, small orbit, fading trail, settle, original still. Avoid rapid flashes. Frame 8 should match frame 1 so the return to the still image is smooth. The animation plays once on activation and carries no voting or like counter.

Initial subjects:

- Official GO Asset Contributor: a compact asset crate, cube or creative toolkit.
- GO LAN Party: a game controller with a friendly local-network motif.
- GO Event Participant: a star, ticket or community orbit.

Suggested Comfy brief: create eight consistently framed animation poses of the same magenta game-development achievement stamp, transparent background, crisp silhouette, simple readable center symbol, subtle spark/orbit activation, no lettering. Arrange the approved poses left-to-right as the specified PNG strip.

Place reviewed files under `public/stamps/`, for example `public/stamps/go-lan.png`. Staff can choose `/stamps/go-lan.png` when issuing an event stamp. Existing art remains optional; built-in icons and CSS feedback work now.

For asset-contribution stamps, update the server-owned default artwork mapping after approving the contributor stamp design. Never put animation scripts or remote HTML into a stamp.
